Como criar o repositório e o token (uma vez só)
  1. Repositório: em github.com/new, crie um repositório chamado minhas-financas-dados, marcado como Private. Não precisa adicionar nada nele.
  2. Token: em github.com/settings/personal-access-tokens/new, dê um nome (ex.: minhas-financas), validade de 1 ano, e em Repository access escolha Only select repositories → selecione o minhas-financas-dados.
  3. Em Permissions → Repository permissions, mude Contents para Read and write.
  4. Clique em Generate token, copie o código github_pat_… e cole aqui.

O token fica salvo só neste aparelho. Quando o token vencer, é só gerar outro e colar de novo.
